    Conseils
    
          
      
            
    • Le style fonctionne par tags séparés par des virgules : genre, instruments, ambiance, type de voix.
      • 
            
    • Structurez les paroles avec [Verse], [Chorus], [Bridge] : le modèle s'en sert pour construire la chanson.
      • 
            
    • Pas de refrain ? Ajoutez [instrumental] dans les paroles.
      • 
            
    • Une génération décevante ? Relancez avec la même grille mais une graine différente.
      • 
            
    • Les fichiers sont enregistrés dans Mes chansons — vous pouvez les copier où vous voulez.
      • 
          
    
          
    Les 3 règles d'or des paroles
    
          
      
            
    1. Structurez : [Verse], [Chorus], [Bridge], et laissez [Intro] / [Interlude] vides pour de l'instrumental.
      2. 
            
    2. Répétez le refrain mot pour mot à chaque passage, avec 6 à 10 syllabes par ligne.
      3. 
            
    3. La durée suit les paroles : ≈ 10 s par ligne, 6 minutes maximum.
      4. 
          
    
          
    Guide complet, avec une chanson prête à coller : GUIDE-PAROLES.md dans le dossier de l'application.
